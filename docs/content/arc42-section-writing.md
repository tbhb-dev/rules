# Arc42 section writing

- Use the [section template](arc42-section-template.md).
- Keep the section focused on its arc42 concern.
- Describe current responsibilities and constraints with concrete names.
- Link decisions instead of repeating their rationale.
- Link relevant workspace views and explain what each diagram shows.
- State unknown facts explicitly. Omit unsupported claims.
- Run documentation, spelling, and prose checks before review.

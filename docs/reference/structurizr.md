# Structurizr macro reference

Load `structurizr_workspace` from `@tbhb_rules_structurizr//:defs.bzl`. Paths are relative to the target package.

```starlark
structurizr_workspace(
    name = "architecture",
    dsl = "docs/architecture/workspace.dsl",
    workspace_json = "docs/architecture/workspace.json",
    diagrams_dir = "docs/architecture/diagrams",
)
```

## Targets and checks

- Run `bazel run :architecture` to refresh committed JSON and images and remove orphan images. Declare local imports in `data`.
- Build `:architecture.renders` for JSON, PlantUML text, SVG, and PNG exports. Each view has a main diagram and a legend.
- Run `:architecture_test` for lint, freshness, and PNG checks.
- Lint always runs `validate -w` and `inspect -w -s error,warning`. Inspections with severity `ERROR` or `WARNING` fail. Severities `INFO` and `IGNORE` pass. Command errors fail too. The runner also looks for violation lines in what `inspect` prints. Other output passes.
- Freshness compares JSON and SVG bytes and reports that those exports are current. Its success message states that it didn't compare PNG bytes. Linux x86_64 and macOS arm64 produce byte-identical JSON and SVG output, checked against the committed files. Linux arm64 is in the CI plan but has no recorded measurement, and macOS x86_64 has no CI leg. The Java virtual machine uses Coordinated Universal Time (UTC) and the en_US.UTF-8 locale. Missing or orphan SVGs and PNGs fail on every platform.
- PNG checks compare bytes and report that committed PNG exports are current only on macOS arm64. Stale PNGs fail only there, and the update target writes PNGs only there. PNG measurements use Structurizr 2025.11.09, Temurin 21.0.13+9, PlantUML 1.2026.10, and Liberation Sans 2.1.5. Preserve generated bytes in Git and exclude them from text formatters.
- The CI plan selects Linux x86_64, Linux arm64 and macOS arm64 for Structurizr and excludes Windows because the Java runtime pins cover Linux and macOS only.
- Rendering uses a pinned Java runtime in headless mode and `!pragma layout smetana`. Graphviz is unnecessary. Java HTTP and HTTPS requests use an unreachable proxy. PlantUML uses its sandbox security profile.
- On Linux, fonts come from the pinned directory only through a generated `FONTCONFIG_FILE`, with a cache under the render scratch directory, and Linux requires host `libfontconfig` and `libfreetype`. On macOS, nothing restricts host fonts. On both platforms the renderer checks that the Java virtual machine opens each pinned TrueType font and that each SVG specifies Liberation Sans. A manual run on macOS arm64 showed the font log lists the pinned fonts with the pinned directory and lists none without it. No test covers those failures.
- Treat workspace sources as trusted input. The `!script`, `!plugin`, and absolute `!include` directives can access the host despite the HTTP(S) proxy and PlantUML sandbox. The pinned command-line tool doesn't expose a restricted mode for validation, inspection, or export. Use trusted workspace sources and imports. Name the source `workspace.dsl`.

## Tool pins

- Keep literal `http_archive` and `http_file` declarations in `pins/extensions.bzl`. They pin the Structurizr command-line tool at 2025.11.09, the Temurin Java runtime at 21.0.13+9, and the PlantUML build under the Massachusetts Institute of Technology (MIT) license at 1.2026.10, plus Liberation Sans 2.1.5 under the `SIL OFL 1.1` license. Bazel verifies Secure Hash Algorithm 256 digests. Renovate reads versions from the release URLs of Structurizr, PlantUML, and Temurin. It can't parse the Liberation Sans attachment URL and doesn't update the Temurin `strip_prefix`, so change those by hand.
- Use `override_repo` to replace the `tbhb_rules_structurizr_cli`, `tbhb_rules_jre`, `tbhb_rules_plantuml`, or `tbhb_rules_liberation_fonts` hub. Java runtime pins cover Linux and macOS on x64 and arm64.
- Download each release asset outside the source tree before updating pins. Compute its digest and compare published checksums. Change each URL, digest, and archive prefix together. Repeat lint, failure proofs, and rendering stability measurements before updating fixtures.
- Preserve upstream license notices in downloaded repositories. Structurizr uses `Apache-2.0`, the PlantUML build uses `MIT`, and Temurin uses `GPL-2.0` with the Classpath exception. Liberation Sans 2.1.5 uses `SIL OFL 1.1` (`SIL-OFL-1.1`). Downloaded tools stay outside the source tree.

# Structurizr macro reference

Load `structurizr_workspace` from `@tbhb_rules_structurizr//:defs.bzl`. Paths are relative to the target package.

```starlark
structurizr_workspace(
    name = "architecture",
    dsl = "docs/architecture/workspace.dsl",
    workspace_json = "docs/architecture/workspace.json",
    diagrams_dir = "docs/architecture/diagrams",
)
```

`bazel run :architecture` refreshes committed JSON and images and removes orphan images. `:architecture.renders` exports JSON, PlantUML text, SVG and PNG files. Each view has a main diagram and a legend. Declare local imports in `data`.

`:architecture_test` groups lint, freshness and PNG tests. Lint always runs `validate -w` and `inspect -w -s error,warning`. ERROR and WARNING inspections fail; INFO and IGNORE do not. Command errors also fail. Inspection output is checked as well as exit status because the violation count can wrap the process status.

Freshness compares JSON and SVG bytes and rejects missing or orphan images. PNG bytes are compared only on macOS arm64: two separate JVM runs produced identical bytes there. Linux and macOS x64 PNG stability has not been measured. Windows is unsupported. Preserve generated bytes in Git and exclude them from text formatters.

Rendering uses a pinned JRE in headless mode and `!pragma layout smetana`; Graphviz is unnecessary. Java HTTP and HTTPS requests use an unreachable proxy and PlantUML uses its sandbox security profile.

## Tool pins

Literal `http_archive` and `http_file` declarations in `pins/extensions.bzl` pin Structurizr CLI 2025.11.09, Temurin JRE 21.0.13+9 and PlantUML MIT 1.2026.10. Bazel verifies SHA-256 digests. Renovate reads the release versions from the URLs.

The tool hubs are `tbhb_rules_structurizr_cli`, `tbhb_rules_jre` and `tbhb_rules_plantuml`. Consumers can replace a hub with `override_repo`. The JRE pins cover Linux and macOS on x64 and arm64.

To bump a tool, download each release asset outside the source tree, compute its SHA-256 and compare published checksums. Update each literal URL, digest and archive prefix together. Preserve upstream license notices in downloaded repositories. Repeat lint, failure proofs and rendering stability measurements before updating fixtures. Structurizr uses Apache-2.0, the PlantUML MIT build uses MIT, and Temurin uses GPL-2.0 with the Classpath exception; downloaded tools remain outside the source tree.

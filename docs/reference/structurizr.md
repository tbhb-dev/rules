## Targets and checks

- Run `bazel run :architecture` to refresh committed JSON and images and remove orphan images. Declare local imports in `data`.
- Build `:architecture.renders` for JSON, PlantUML text, SVG, and PNG exports. Each view has a main diagram and a legend.
- Run `:architecture_test` for lint, freshness, and PNG checks.
- Lint always runs `validate -w` and `inspect -w -s error,warning`. Inspections with severity `ERROR` or `WARNING` fail. Severities `INFO` and `IGNORE` pass. Command errors fail too. The runner also reads what `inspect` prints, because the violation count can wrap the process status.
- Freshness compares JSON and SVG bytes on every supported platform (Linux and macOS on x64 and arm64). Linux x86_64 CI proved SVG and JSON byte-identical to the committed files generated on macOS arm64. The Java virtual machine uses Coordinated Universal Time (UTC) and the en_US.UTF-8 locale. Missing or orphan images fail on every supported platform.
- PNG checks compare bytes only on macOS arm64. PNG measurements use Structurizr 2025.11.09, Temurin 21.0.13+9, PlantUML 1.2026.10, and Liberation Sans 2.1.5. Preserve generated bytes in Git and exclude them from text formatters.
- The CI plan selects Linux x86_64, Linux arm64 and macOS arm64 for Structurizr and excludes Windows because the Java runtime pins cover Linux and macOS only. The observed CI run at `37704af1` ran Structurizr only on Linux x86_64. Linux arm64, macOS and Windows renders remain unmeasured by CI. SVG metrics on other platforms remain unmeasured by CI.
- Rendering uses a pinned Java runtime in headless mode and `!pragma layout smetana`. Graphviz is unnecessary. Java HTTP and HTTPS requests use an unreachable proxy. PlantUML uses its sandbox security profile.
- Fonts come from the pinned directory only through a generated `FONTCONFIG_FILE`, with a cache under the render scratch directory. The renderer checks that the Java virtual machine opens each pinned TrueType font and each SVG specifies Liberation Sans. Linux requires host `libfontconfig` and `libfreetype`.
- Treat workspace sources as trusted input. The `!script`, `!plugin`, and absolute `!include` directives can access the host despite the HTTP(S) proxy and PlantUML sandbox. The pinned command-line tool doesn't expose a restricted mode for validation, inspection, or export. Use trusted workspace sources and imports. Name the source `workspace.dsl`.

Frontmatter `at` timestamps use Coordinated Universal Time (UTC).

# Structurizr macro reference

Load `structurizr_workspace` from `@tbhb_rules_structurizr//:defs.bzl`. Paths are relative to the target package.

```starlark
structurizr_workspace(
    name = "architecture",
    dsl = "docs/architecture/workspace.dsl",
    workspace_json = "docs/architecture/workspace.json",
    diagrams_dir = "docs/architecture/diagrams",
)
```

## Targets and checks

- Run `bazel run :architecture` to refresh committed JSON and images and remove orphan images. Declare local imports in `data`.
- Build `:architecture.renders` for JSON, PlantUML text, SVG, and PNG exports. Each view has a main diagram and a legend.
- Run `:architecture_test` for lint, freshness, and PNG checks.
- Lint always runs `validate -w` and `inspect -w -s error,warning`. Inspections with severity `ERROR` or `WARNING` fail. Severities `INFO` and `IGNORE` pass. Command errors fail too. The runner checks inspection output because the violation count can wrap the process status.
- Freshness compares JSON and SVG bytes and rejects missing or orphan images on all supported platforms.
- PNG checks compare bytes only on macOS arm64. Two separate Java virtual machine runs produced identical bytes there. Linux and macOS x64 lack stability measurements. Windows is unsupported. Preserve generated bytes in Git and exclude them from text formatters.
- Rendering uses a pinned Java runtime in headless mode and `!pragma layout smetana`. Graphviz is unnecessary. Java HTTP and HTTPS requests use an unreachable proxy. PlantUML uses its sandbox security profile.

## Tool pins

- Keep literal `http_archive` and `http_file` declarations in `pins/extensions.bzl`. They pin the Structurizr command-line tool at 2025.11.09, the Temurin Java runtime at 21.0.13+9, and the PlantUML MIT build at 1.2026.10. Bazel verifies Secure Hash Algorithm 256 digests. Renovate reads versions from release URLs.
- Use `override_repo` to replace the `tbhb_rules_structurizr_cli`, `tbhb_rules_jre`, or `tbhb_rules_plantuml` hub. Java runtime pins cover Linux and macOS on x64 and arm64.
- Download each release asset outside the source tree before updating pins. Compute its digest and compare published checksums. Change each URL, digest, and archive prefix together. Repeat lint, failure proofs, and rendering stability measurements before updating fixtures.
- Preserve upstream license notices in downloaded repositories. Structurizr uses `Apache-2.0`, the PlantUML MIT build uses `MIT`, and Temurin uses `GPL-2.0` with the Classpath exception. Downloaded tools stay outside the source tree.
